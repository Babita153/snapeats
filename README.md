# 🍔 SNAPEATS - Food Delivery App

A full-stack food delivery mobile application built using React Native.

## 🚀 Features
- 🔐 User Authentication (Login / Signup)
- 🍕 Browse Food Items
- 🛒 Add to Cart
- 📦 Place Orders
- 👤 User Profile

## 🛠️ Tech Stack

### Frontend:
- React Native

### Backend:
- Node.js
- Express.js

### Database:
- MongoDB


## 📂 Project Structure

SNAPEATS/
 ├── backend/
 ├── frontend/


## ⚙️ Installation

### Backend:
cd backend  
npm install  
npm start  

### Frontend:
cd frontend  
npm install  
npx react-native run-android
